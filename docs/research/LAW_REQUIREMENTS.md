조사일 2026-11-21. 근거는 국가법령정보센터 원문과 개인정보보호위원회 발간물, 대회 공식 기준.

### D. 사진과 위치

- **EXIF GPS**: 위치정보법 제2조제1호는 위치정보를 "**전기통신설비 및 전기통신회선설비를 이용하여 측위된 것**"으로 정의한다. 카메라 EXIF의 GPS는 위성항법(GNSS) 측위여서 문언상 그 요건에 정확히 들어가지 않는다. 다만 **A-GPS처럼 통신망을 보조로 쓰는 측위가 흔하고, 법원·학계 해석이 확립돼 있지 않다.** → **확인(조문) / 추정(적용)**
- 위치정보법 **제15조제1항은 "누구든지"** 개인위치정보주체 동의 없이 수집·이용·제공 금지. 위반 시 3년 이하 징역 또는 3천만원 이하 벌금(제40조4호). 사업자 지위와 무관하게 적용된다. → 확인
- 실무 결론: EXIF GPS가 위치정보법상 "위치정보"인지 다투지 말고 **EXIF를 수신 즉시 제거**하고, 제거 전에는 개인정보(그리고 잠재적 개인위치정보)로 취급한다. → 판단
- **사진 속 제3자(이웃·가족·아동)**: 그 사람의 영상은 그 사람의 개인정보이고, 만 14세 미만이면 제22조의2가 걸린다. 제35조④2(다른 사람의 생명·신체·재산 침해 우려 시 열람 제한)와 제34조(유출 통지)도 제3자 단위로 발생한다. → 확인(조문) / 적용 판단
- **주거 내부 사진**: 개인정보(영상 + 생활 정보)에 해당. 민감정보 해당 여부는 시행령 제18조 각 호(유전정보·범죄경력·생체특징·인종)에 없으므로 **원칙적으로 민감정보 아님**. 단 처방전·약봉투·진단서가 찍히면 '건강'에 관한 정보로서 민감정보(법 제23조 본문)가 된다. → 확인(조문) / 추정(사진별 판단)
- 사생활 침해 소지: 헌법 제17조(사생활의 비밀과 자유), 민법 제750·751조(불법행위·위자료). → 확인(조문)

### E. AI 기본법 — 이 앱에 실제로 적용되는 의무

- **제4조제1항**: "국외에서 이루어진 행위라도 국내 시장 또는 이용자에게 영향을 미치는 경우 적용". → 확인
- **제2조제4호 고영향 AI**: 에너지 공급 / 먹는물 생산 / 보건의료 / 의료기기 / 원자력 / 범죄수사 생체인식 / **채용·대출 심사 등 권리·의무에 중대한 영향** / 교통수단·시설 운영 / 국가기관등 의사결정 / 유아·초·중등 학생 평가 / (카목) 대통령령 지정. **시행령에는 카목 추가 영역이 아직 없다**(시행령 제25조는 확인 절차만 규정). → **주거 하자 진단은 열거 영역에 해당하지 않음. 고영향 AI 아님.** 확인(조문) / 판단(적용)
- **제31조제1항**: 인공지능사업자가 **생성형 AI를 이용한 서비스**를 제공하려면 "해당 인공지능에 기반하여 운용된다는 사실을 이용자에게 **사전에 고지**". → **적용됨**(LLM 초안 생성 경로가 이미 존재).
- **제31조제2항**: "그 결과물이 생성형 인공지능에 의하여 생성되었다는 사실을 **표시**". → 적용됨.
- **위반 시 과태료 3천만원**(제43조제1항제1호). → 확인
- **제31조 시행령 제23조①**: 고지 방법 = 제품·계약서·이용약관 기재 / 화면·단말 표시 / 장소 게시 / 과기정통부 인정 방법. **제4항 면제**: 서비스명·화면상 명백한 경우, 내부 업무용, 과기정통부 고시. → 확인

### F. 대회 규정 — 법보다 엄격한 별도 상한

「AI 해커톤_AI 활용 및 출처 표기 기준」(2026.11.03. 배포, 첨부3) **제7조 「개인정보 보호 및 보안」**:

> "본 대회에서는 **동의 여부와 관계없이** 외부 AI 서비스(API 포함)에 실제 개인정보·민감정보를 입력하거나 학습·시연 용도로 전송하는 행위를 금지함. 외부 서비스에는 가상 데이터 또는 **개인을 알아볼 수 없도록 처리된 데이터**만 사용함."

제3조 금지 항목에도 동일 취지가 반복된다. **제8조 위반 시 조치**: "저작권·라이선스·개인정보 침해 → 위반의 중대성에 따라 보완 요청, **심사 제외** 또는 **수상 취소(상금·상장 반환 포함)**". 대회 안내 페이지도 "저작권·라이선스·개인정보 침해 … 중대성에 따라 보완 요청, 심사 제외 또는 수상 취소"를 명시. → **확인**

즉 **법적으로는 동의로 해결될 수 있는 전송도, 이 대회에서는 동의로 해결되지 않는다.** 이 한 줄이 설계의 상한을 정한다.

같은 기준 제7조는 "서비스 화면에서 AI가 생성한 응답·이미지임을 사용자가 알 수 있도록 표시할 것을 **권장**"하며, 각주로 "**「인공지능기본법」 제31조**는 … 사전 고지와 생성형 AI 결과물 표시 의무를 규정"한다고 스스로 안내한다. → 대회가 AI 기본법 제31조를 인지하고 있음. 확인

### P1-6. "비식별"이라는 단어를 쓸 수 있는 조건을 팀 내부에서 고정해야 한다

- (a) 제2조1호다목(가명정보), 제58조의2(익명정보), 「가명정보 처리 가이드라인」(2026.3) 제3장 — "완벽하게 탐지·처리할 수 있는 기술이 부재", "재식별 위험 0을 목표로 하지 않음"
- (b) "익명정보"라고 주장하려면 그 입증 부담이 처리자에게 있다. 근거 없이 "비식별 완료"라고 제출물·화면에 쓰면 허위 기재로 심사 제외 사유(대회 기준 제8조)
- (c) **표현 규칙**: "익명/비식별" 대신 **"개인 식별 요소를 제거한 사본"**이라고 쓴다. 그리고 아래 체크리스트를 통과한 경우에만 그 표현을 쓴다:
  - 원본 파일은 전송 후 파기, 사본만 전송
  - ① 얼굴·신체 ② 문서·서류의 텍스트(이름·주민번호·계좌·진단명) ③ 주소·동·호수·문패·택배 라벨 ④ EXIF(GPS·촬영일시·기기) ⑤ 반사상(거울·창문·TV·액자) ⑥ 차량번호 ⑦ 이웃·가족 ⑧ 특이 물건(반려동물·취미용품) — 8개 항목 제거 확인
  - **하나라도 남으면 "비식별"이라고 쓰지 않는다.** 특히 반사상과 문패는 육안 검수 없이는 못 잡는다 → 사람이 1회 확인한 사진만 허용목록에 넣는다

### P1-7. EXIF는 "전송본에 없다"가 아니라 "수신 즉시 제거"로 만들어야 한다

- (a) 위치정보법 제2조1호·제15조제1항, 개인정보보호법 제16조①(최소수집)
- (b) 위치정보법 제15조①4호 위반 시 3년/3천만원(제40조4호). 그리고 이건 **코드 변경 없이 주석 한 줄로 방어 가능한 리스크**다
- (c) `_decode_photo` 직후 `img.info.pop("exif", None)` + `img.getexif().clear()`를 명시적으로 호출하고 "EXIF는 디코드 직후 폐기, 전송본은 PNG 재인코딩"을 주석으로 남긴다. 현재도 결과적으로 안전하지만 **의도된 안전**이 아니라 **부수 효과**라서, 누군가 JPEG로 저장하도록 바꾸면 조용히 깨진다

### P1-8. 처리방침에 국외이전 표를 넣어야 한다 (앱 내 1개 화면)

- (a) 제30조① + 시행령 제31조①2, 제28조의8제2항
- (b) 미작성·미공개 과태료 1천만원(제75조④8). 국외이전 고지 누락은 PIPC 실태점검에서 실제 지적된 유형(제2024-010-184호)
- (c) 처리방침 화면에 **8행 표**: 근거 / 이전 항목 / 이전 국가 / 시기·방법 / 이전받는 자(명칭·연락처) / 이용 목적 / 보유·이용기간 / 거부 방법·효과. Meta(`api.meta.ai`, 미국)와 LLM 제공자 2행이면 끝난다
- 함께: 학습 미이용·미저장을 **계약으로 확인한 경우에만** "학습에 사용하지 않습니다"라고 쓴다(P1-9)

### P1-9. 외부 AI 사업자와의 위탁 관계를 문서로 남겨야 한다

- (a) 제26조제1항 + 시행령 제28조①(5항목: 목적·범위 / 재위탁 제한 / 접근제한·안전조치 / 관리현황 점검·감독 / 수탁자 의무 위반 시 손해배상), 제26조제2항(공개)

- (c) 마감 전에는 **불가능**하다. 대신:
  1. 제출물 "외부 자원·출처" 별첨에 사업자·약관·DPA·데이터 처리 국가·보존 정책 링크를 적고 **"확인 완료/미확인"을 정직하게 표기**

  3. 본선 전까지 해당 사업자의 엔터프라이즈 약관·DPA 원문을 확보해 1쪽 요약

### P1-11. 고영향 AI 해당 여부 사전 검토를 1쪽으로 남겨야 한다

- (a) AI 기본법 제33조제1항("사전에 검토하여야")
- (b) 과태료 규정은 없으나, 검토 기록이 없으면 "고영향 아님"을 사후에 주장할 근거가 없다. 본선 질의에서 나올 수 있다
- (c) `docs/research/AI_HIGH_IMPACT_REVIEW.md` 1쪽: ①제2조제4호 가~차목 대조표(전부 "해당 없음" + 이유) ②카목 대통령령 미정 확인 ③결론 "고영향 AI 아님, 제31조만 적용" ④검토일·검토자

### P1-12. 보유기간과 파기를 항목별로 정해야 한다

- (a) 제21조①·②, 제30조①2·3의2, 시행령 제16조①1(전자적 파일은 복원 불가하게 영구 삭제)
- (b) 파기 미이행 과태료 3천만원(제75조②4). "무기한 보관"은 그 자체로 위반
- (c) 표 한 줄씩:
  - 원본 사진: **요청 처리 즉시**(현재 구현) — 처리방침에 그대로 쓴다
  - 외부 전송 사본: 전송 후 메모리에서 폐기, 디스크 미기록
  - 탐지 메타데이터(bbox·label·confidence·mask): 기록 보존 목적, **명시 기간**(예: 회원 탈퇴 시 또는 1년) 설정 후 기재
  - 동의 이력: 철회 후에도 **철회 사실 입증분만** 분리 보관(제21조③)
  - 접속기록: 고시 기준 확인 후 기재 (→ 미확인 항목)
- **주의**: 마스크·bbox만 남겨도 "우리 집 구조 + 하자 위치"는 개인정보일 수 있다. "사진을 저장하지 않으므로 개인정보가 없다"는 논리는 성립하지 않는다

### P1-13. 만 14세 미만 아동 관련 처리를 차단해야 한다

- (a) 제22조의2제1항, 시행령 제17조의2, 제71조3호
- (b) 법정대리인 동의 없이 아동 개인정보 처리 시 5년/5천만원 + 과징금(제64조의2①2)
- (c) 실서비스 전에는 연령 확인이 필요하지만, 데모에서는 **아동이 등장하는 사진을 허용목록에서 제외**하는 것으로 충분. 처리방침에 "만 14세 미만 아동의 사진은 처리하지 않습니다" + 위반 시 삭제 절차 1줄. 사진에 아동이 찍힌 경우를 탐지할 방법은 없으므로 **사람 검수**가 유일한 통제

### P2-14. 로그·백업·DB 리전을 확정해야 한다

- (a) 제29조 + 시행령 제30조①5(접속기록), 제28조의8(국외 이전은 보관·조회도 포함)
- (b) Supabase 리전이 국외면 **DB 자체가 국외 이전**이다. 지금은 미확인 상태
- (c) `.env`에서 리전 확인(예: `ap-northeast-2`), 백업 보존기간 확인, 접속기록 보관기간을 고시 기준에 맞춰 설정. 데모에서는 "원본 미보관 + 로그에 이미지·프롬프트 미기록"을 코드 주석과 제출물로만 입증

### P0-15. 제출물에 개인정보 처리 설명을 별도 섹션으로 넣어야 한다

- (a) 대회 기준 제4조(AI 활용내역 3,000자), 제5조(외부 자원·출처 표), 제7조, 제9조 체크리스트
- (b) 체크리스트 마지막 항목이 "외부 AI 서비스에 실제 개인정보를 입력하지 않았음"을 **확인**하는 항목이다. 서명 대신 서술로 답해야 한다
- (c) 프로젝트 소개서에 4~6줄: ①원본 미보관 ②EXIF 폐기 ③허용목록 샘플만 외부 전송 ④동의 거절 시 폴백 ⑤AI 기본법 제31조 고지 적용 ⑥**"대회 기준 제7조에 따라 실제 개인정보는 외부 AI로 전송하지 않음"** 명시. 3,000자 안에 이 6줄을 넣는 것이 다른 어떤 기능 설명보다 감점 방어에 효율적

## 4. 한 줄 결론

법적으로는 "동의 + 고지 + 국외이전 5항목 + 처리방침"으로 이 기능을 적법하게 만들 수 있다.
그러나 **이 대회에서는 동의가 면죄부가 되지 않는다**(기준 제7조). 따라서 11-23까지의 정답은 하나다.

> **외부 AI로 나가는 것을 샘플 허용목록으로 물리적으로 제한하고, 동의·고지·폴백·AI 표시는 "법을 이해하고 설계했다"는 증거로 화면에 남긴다.**

동의 UI를 만드는 목적은 "동의를 받아 전송하기"가 아니라 **"동의를 받아도 전송하지 않는 구조"를 보여주는 것**이다. 이 프레이밍이 심사에서 가장 방어적이다.
