# 0001. 사진 관찰과 텍스트 진단을 2단계로 분리

사진에서 확인 가능한 사실(하자 흔적·의심 유형·화면 점유 비율·대략 위치)과, 사진과 입력을 종합한 추정(심각도·원인·대응)은 신뢰 수준이 다르므로 한 번의 모델 호출로 섞지 않는다. 1단계 `vision.py`는 YOLO 탐지와 Meta SAM 3.1 분할을 수행하고, 판독하지 못한 사진만 비전 LLM이 독립적으로 관찰한다. 2단계 `diagnosis.py`는 1단계 관찰 요약과 위치·재질·증상만 텍스트 LLM에 전달해 구조화 진단을 만든다.

- **대안**: 단일 멀티모달 호출로 관찰·진단을 함께 생성. 좌표가 필요 없고 구현은 짧지만, YOLO·SAM 결과를 재사용할 수 없고 사진별 실패를 분리하기 어렵다.
- **결과**: 사진별 `failed`/`analyzed` 상태를 남기고 진단은 계속 진행할 수 있다. 원시 좌표·마스크는 진단 프롬프트에 넣지 않아 개인정보·프롬프트 크기 위험을 줄인다. 모델·프롬프트 교체 지점이 두 파일로 나뉜다.
