# 0002. 하자 사진을 비공개 Storage 버킷과 단기 Signed URL로 보관

기존 "원본 사진 미저장" 정책을 개정해, 견적 요청서 공유와 결과 재열람에 필요한 하자 사진을 Supabase Storage 비공개 버킷에 저장하고 앱에는 짧은 만료의 Signed URL만 발급한다. 사진 객체 경로는 기록 소유자와 연결하고, 서버가 소유권을 확인한 뒤 URL을 생성한다.

- **대안**: 기존처럼 원본을 저장하지 않고 분석 결과만 보관. 저장 위험이 없지만 요청서에 사진을 첨부하거나 나중에 결과를 다시 볼 수 없다.
- **결과**: 공개 버킷·영구 URL을 쓰지 않아 URL 유출 시에도 접근이 만료된다. 보유기간·삭제 정책과 국외 이전 동의 문구는 별도 개인정보 검토가 필요하다. (구현 예정)
