# 0003. 지역·특화 분야 기반 공개 견적 요청과 제안 매칭

요청인은 하자 기록을 견적 요청서로 공개하고, 등록 지역과 작업 종류가 맞는 업체가 제안서를 제출하며, 요청인은 여러 제안서 중 하나를 수락해 매칭을 확정한다. 요청서는 1:N으로 공개되고 수락은 요청서당 1건만 허용한다.

- **대안**: 업체별 1:1 견적 요청. 구현은 단순하지만 요청인이 여러 업체를 직접 찾아야 하고 비교가 어렵다.
- **결과**: 지역·작업 종류 필터로 후보를 좁히고 제안을 비교할 수 있다. 수락 시 나머지 제안은 자동 종료하며, 금액·일정은 업체가 입력한 값만 저장한다. 요청서당 공개 1건·업체당 제안 1건·수락 1건을 DB 제약으로 강제하고, 업체에게는 경쟁 제안서를 노출하지 않는다.
