# 백엔드 구현 체크리스트

2026년 11월 20일 팀 회의 변경 사항과 현재 구현 상태를 기준으로 정리한 체크리스트다. 체크된 항목은 현재 저장소에 구현된 기능이며, 변경된 MVP 설계 중 소식지, 실제 모델 기반 일괄 분석·진단, 업체 1:1 채팅, 회원가입 화면·4개 탭은 후속 구현 대상이다. 실제 Supabase·모바일·외부 모델을 함께 연결한 검증은 별도 항목으로 관리한다.

현재 코드에는 DB·인증·기록 CRUD(`material` 포함), **입력값 기반 샘플 일괄 분석(`POST /records/{record_id}/analyze`)**, 사진·입력·결과 화면, **회원 프로필 API(`GET/PUT /me/profile`)·지역 목록(`GET /regions`)·내 기록 목록(`GET /records`)**, 모바일 프로필·기록 화면, 그리고 **레거시/보류 상태인 AI 추가 질문 대화 API(`messages`, `next-question`)**가 구현되어 있다. 다음 핵심 작업은 소식지(`GET /support-programs`), 실제 사진/LLM 기반 진단, 업체 검색·1:1 채팅 구현이다.

## 회원·인증

회원 인증은 Supabase Auth(이메일·비밀번호)가 담당한다. 모바일 앱은 Supabase에 로그인하고 FastAPI는 전달받은 액세스 토큰으로 사용자와 리소스 소유권을 확인한다. 일반 회원가입은 `요청인` 전용이며 `닉네임`, `ID(이메일)`, `PW`, `거주 지역`(필수), `등록 주소`(선택), `거주 형태`(`월세`, `전세`, `반전세`, `자가`, `기타`)를 입력받는다. 시연용 `업체` 계정은 사전 등록한다. 비밀번호 재설정은 후속 범위다. [기존 결정](PROJECT_PLAN.md#합의한-범위)
