## 0. 결론 요약

1. **지금 상태로는 불가.** 사진을 외부로 보내는 경로가 "동의 boolean + 키 존재"만으로 열려 있어 `기준` 제7조("동의 여부와 관계없이 금지")를 구조적으로 위반한다 (`vision.py:174`).
2. 가능하게 만드는 방법은 **데이터 속성 하나뿐**이다. 동의가 아니라 "가상·샘플·개인 식별 요소를 제거한 사본"만 나가야 한다 (`기준` 제7조).
3. **실제 텍스트 LLM은 Gemini다.** `.env`의 `LLM_BASE_URL=generativelanguage.googleapis.com`, `LLM_MODEL=gemini-4-hydrogen`. "OpenAI"로 기재하면 `기준` 제8조 허위 기재다.
4. **가장 큰 리스크: 실사진 1장이 외부로 나가면 심사 제외·수상 취소(상금·상장 반환).** `기준` 제3조 금지목록 → 제8조.
5. 이 문서 범위 밖의 더 급한 치명 리스크가 하나 있다 — **심사위원이 실행할 프로토타입이 없다** (`EXPO_PUBLIC_API_URL=http://127.0.0.1:8000`, 배포 산출물 0건). §7에 배치했다.

> **한 줄 판정**: 사진 외부 전송을 **0으로 두면(A-0) 지금 상태로도 규정상 가능**하고, 켜려면 최소 6개 작업 + 사무국 회신이 필요하다.

**무료 티어를 쓰면 안 되는 이유 3줄**
1. Gemini 무료는 "인간 검토자가 읽을 수 있다"고 약관에 명시돼 있다(`확인`).
2. `기준` 제7조는 "**학습**·시연 용도로 전송하는 행위"를 금지한다. 무료 등급 사용 = 제공사 학습 목적 사용 → 문언 충돌.
3. 대회가 "무료 도구도 가능"(`기준` 제2조①)이라고 한 것은 **도구 선택의 자유**를 뜻하지, 제공사 정책의 안전을 보증하지 않는다.

**ZDR(무보관)은 어디서도 못 얻는다.** OpenAI·Anthropic 모두 영업 승인/계약 필요 `확인`. "ZDR 확보"를 전제로 설계하면 안 된다.
